# Уведомления ChatGPT о синхронизации СКТ-225

GitHub Actions выполняет синхронизацию на сервере. ChatGPT читает компактный отчёт через GitHub в режиме чтения.

Настройте одну почасовую задачу ChatGPT на 35-й минуте UTC. В старой задаче замените инструкции целиком и дайте завершиться уже начатому запуску. Удалите подключение Google Calendar из этой задачи, если интерфейс позволяет выбрать приложения для отдельной задачи. Проверьте историю её запусков перед включением режима записи в GitHub Actions.

## Промпт для ChatGPT

```text
Каждый час на 35-й минуте UTC проверяй синхронизацию расписания СКТ-225. Используй подключение GitHub только на чтение.

Открой файл latest.json в ветке calendar-sync-reports репозитория retr0-pm/sarov-schedule-skt225. Прочитай его через инструмент GitHub для чтения файла по имени ветки и пути. Если этот метод недоступен, попробуй прочитать https://raw.githubusercontent.com/retr0-pm/sarov-schedule-skt225/calendar-sync-reports/latest.json.

Уведомляй кратко, когда есть созданные, изменённые или удалённые занятия, конфликт, заблокированные операции, ошибка либо отчёт отсутствует или старше трёх часов. Укажи время отчёта, статус, числа операций и ссылку https://github.com/retr0-pm/sarov-schedule-skt225/actions/runs/<run_id>. Если тот же run_id и run_attempt уже сообщались, пропусти повтор. При success без изменений не присылай подробностей. При dry_run обозначай операции как запланированные. При disabled сообщи один раз, что запись пока отключена. Успешность календарной проверки подтверждается verified=true.

Твоя задача ограничена чтением отчёта и уведомлением. Не подключай Google Calendar, не меняй события, не скачивай артефакты с PDF, не запускай GitHub Actions и не записывай файлы в репозиторий.
```

Настройка Google Calendar и порядок активации описаны в [инструкции по развёртыванию](CALENDAR_DEPLOYMENT.md).
